Important exclusions: WuBor `escape_air_slide` introduces airdash tiers, HDR changes dodge timing/staling and ledge behavior, and HDR common.prcxml changes shield health/regen/cancel timing. None is a substitute for a vanilla common.prc dump. The SSBU status-script dump explicitly lacks lua2cpp_common; `vanilla_status` contains selected fighter statuses only. Source proof of parameter names or an algorithm with unknown constants is not a complete trajectory oracle.
