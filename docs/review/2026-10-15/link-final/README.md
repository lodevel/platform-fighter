# Link Final takeover — Ancient Bow and Arrow

The accepted Link body bank already contains genuine native `d04final` and
`d04finalair` drawings. The source choreography requests `final`/`final_air`,
but its early Final art branch skipped ordinary packed-body resolution and
those logical keys were not mapped. The owner could retain its previous art
while the independently implemented Ancient Arrow article still ran.

The new mapping is a genuine same-motion presentation alias to those retained
native clips. It does not convert the old body bank into a newly qualified
SOURCE ROOT/receiving/attachment profile. Link's Final-only source clock starts
at raw sample zero; packed selection takes that age unchanged and adds one
only to compare stored one-based drawing labels. Ground and air have different
sample sets. Four production manifest-catalog tests verify the boundaries:
raw 58/59 select ground drawings 4/5 and air drawings 5/6.

The Ancient Arrow uses its separate actual article: source release at raw
sample 60, native speed 60 and range 600, first fighter/terrain contact followed
by the selected fighter or wall explosion. Packet values and blockability
remain bound through the existing source/Wiki selection. The shared hit
converter already honors Link's native `disableHitlag:true`; it does not apply
the old overnight note's generic victim multiplier. Source-flag conversion and
zero shared hit-stop are covered by `finalPacketHitlag.test.ts`.

`tools/link-final-match-probe.mjs` is the production browser acceptance harness.
It starts actual matches, uses the saved DOM special binding, records actual
submitted owner drawing selection, real article states, damage and victim
hit-stop, and captures the arrow and explosion in the match. Resource grants
and target placement are explicit controlled setup; the target is positioned
at source frame 59 before the real frame-60 arrow release. All collision and
combat decisions remain the real production paths. Acceptance is the report
produced on the coordinator's final cutover build; preparation alone is not
runtime qualification.

This is a source-guided 2D implementation with accepted existing Link artwork,
not exact native renderer/camera/common-dispatch parity. The owner paired
receiving/SOURCE ROOT and common cinematic victim dispatch are not newly
qualified by the presentation alias. Link's source packets disable hit-stop,
so the optional stop-only impact presentation is not artificially admitted.
The actual arrow and code-drawn explosion remain independently visible.
