native moves/status/motion data plus the project's source-guided 2D adapters.

owner body profiles. `finalBodyPose` indexes the exact phase sheet and requires
`coordinateOrigin: actorSourceRoot`; it has no native-name alias. The real
match's contact query returned no contacts without that profile. All three
fighters also lacked the separate required cinematic recipient profiles.

The old October 12 handoff explicitly recorded the 851 DK/Pikachu body drawings
as **uninstalled**, with contact/victim/lease work outstanding. Those staged art
directories are now empty. Native model, motions, source contracts and renderer
tools survived. Neither the frozen prior build nor the current recovery build
contains Pikachu Final body pages. This was unfinished implementation, not a
verified Final implementation subsequently proven to have regressed.

Exact recovery build `assets/index-CoE_sk-F.js`, served on 4173:
[`before/report.json`](before/report.json) records eight arranged match cases:
ground/air × left/right × hit-target/miss-target. Activation uses actual browser
keyboard events through the saved special binding. Resource grants, identity
synchronization and target placement are explicit setup injections. Air hit
targets are placed at the actual dash admission before the next physics step.
All eight activated, ran startup → dash → miss and completed with **zero damage
and zero captures**, including all four targets arranged inside the dash path.
The dash screenshot shows the old idle drawing. No page errors occurred.

Two early probe runs had setup mistakes (injected reset identity and internal
player index versus binding slot) and were discarded; they are not gameplay
evidence. The retained report comes from the corrected probe.

## Bound source kinetics and world policy

The existing miss branch retained the initial dash's native speed 8 throughout
recovery. Captured `FinalDashEnd.txt` and `FinalAirDashEnd.txt` specify initial
miss speed 3; `FinalDashEnd/main.c` reads `final_dash_end_brake_x = 0.09`.
Ground miss also applies motion rate 0.7; air miss does not. The reducer now derives a separate motion age from integer status age,
so ground miss spans 129 fixed steps and air miss 61, while controller age
remains integer. Miss starts at native speed 3 and brakes by 0.09 per step.

`voltTackleWorldPolicy.initialDashCliffStop` was calculated but had no consumer.
Native grounded Dash enables cliff stop after six frames; the grounded miss
helper also selects cliff stop. The new pure projection helper uses an actual
supporting platform and actual Matter hull width; it is a named 2D support
adapter, not a claim to reproduce native contact margins. Air entry remains
separate. The actual MatchSim callback validates the owner
is grounded, reads its real supporting body, checks the live terrain mask,
and projects only its proposed horizontal velocity.

The old miss lease reapplied Y speed zero every step, preventing ordinary air
gravity from accumulating. The narrow owner/miss-only lease flag now preserves
actual current vertical velocity so normal air gravity accumulates. Actual
production physics tests verify falling and grounded edge retention.

## Precision limits

This Final is implemented using retained source mechanics and explicit 2D
adapters. It is not qualified as an exact recreation of Ultimate's native
renderer/engine. TOP is the selected virtual actor-ROOT adapter; native camera
projection/FOV and angle/common-calculation consumers remain approximated by
the accepted deterministic adapter. The recipient cinematic recipes are newly
authored, not native victim motions. Owner art uses a new toon shader and omits
visual helper constraints. Native receiving capsule roles are preserved and
are not asserted tissue-tight. Ground cliff margins are an authored platform
projection, and the native KO_SURVIVE common meaning is not newly established
by this work. Automated arranged matches and visual inspections do not stand
in for human controller play acceptance.
