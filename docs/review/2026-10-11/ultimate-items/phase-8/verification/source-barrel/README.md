# Barrel source verification

Barrel loot count1 remains an explicit authored adaptation. Ultimate Wiki content and retained native workbook/animcmd evidence do not establish a numeric count. Tests passing one-item output verify this implementation, not native parity. Melee-only counts/odds are excluded. See findings.json for the bounded search and retained file hashes.

Slope rolling is a sourced behavior, but the current StagePlatform schema and StageRenderer support axis-aligned rectangular platforms only. No slope angle, polygon or surface normal is exposed. Native Barrel slope_type=slant (item_common DV3) supports native slope-aware presentation, not a recovered roll acceleration/status implementation. The current horizontal rolling path is therefore an engine limitation; no existing slope surface support was overlooked.

HP14, horizontal/vertical caps3, native gravity.25/cap2.5 and ground brake.002 are supported by pinned item_common. Rolling reuses native Throw damage/launch as an explicitly authored adapter, not proof of a recovered native rolling packet; near-zero stop.05px and visual rotation remain authored. Real-Matter method tests cover collision, edge fall and stop/pickup state in the supported flat world.
